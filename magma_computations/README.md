## Code for magma computations

This directory contains the scripts for the magma computations to obtain the outputfiles in the directory `magma_output`.

The computation is explained in Section 4.3 in the paper "The selfprojecting Grassmannian" <https://arxiv.org/abs/2511.21442>

The code originated in the following project, but was enhanced by the authors for a wider application range:

Alheydis Geiger, Sachi Hashimoto, Bernd Sturmfels, Raluca Vlad: Self-dual matroids from canonical curves
In: Experimental mathematics, 33 (2024) 4, p. 701-722
DOI: `10.1080/10586458.2023.2239282 <https://dx.doi.org/10.1080/10586458.2023.2239282>`_ ARXIV: https://arxiv.org/abs/2212.05910 CODE: https://github.com/sachihashimoto/self-dual
