## Output from magma computations

This directory contains the output files of the magma computations done using the code in the directory `magma_computations`.

The computation is explained in Section 4.3 in the paper "The selfprojecting Grassmannian" <https://arxiv.org/abs/2511.21442>

For the computation of the self-projecting realization spaces for rank 5 on 10 elements we refer to https://github.com/sachihashimoto/self-dual
