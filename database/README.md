# database
This GitHub page  contains the database of (self-projecting) realization spaces of self-projecting matroids of rank k on n elments over characteristic zero for (k,n) in {(2,4),...,(2,12),(3,6),(3,7),(3,8),(4,8),(4,9),(5,10)}, as described in the article: <https://arxiv.org/pdf/2511.21442>


**Warning:** This repository is still under construction. The current collection r4n9 is not complete and r5n10 is still missing. These directories will be completed soon! 
If you have any questions, contact the authors.

For the cases {(2,4),(3,6),(4,8),(5,10)} the database stores material from the  article:
Alheydis Geiger, Sachi Hashimoto, Bernd Sturmfels, Raluca Vlad: Self-dual matroids from canonical curves
In: Experimental mathematics, 33 (2024) 4, p. 701-722
DOI: `10.1080/10586458.2023.2239282 <https://dx.doi.org/10.1080/10586458.2023.2239282>`_ ARXIV: https://arxiv.org/abs/2212.05910 CODE: https://github.com/sachihashimoto/self-dual

**Erratum:** In "Self-dual matroids from canonical curves" there are two matroids of rank 4 on 8 elements for which the dimensions of the realization space and the self-dual realization space were computed one dimension too high. These are the matroids "r_4_n_8_index_7" and "r_4_n_8_index_8", in this database, and lines 7 and 8 in https://github.com/sachihashimoto/self-dual/blob/main/rk4.out 
The correct dimensions and Gröbner bases of the realization spaces are contained in this database.

**How to use:**
In order to work with the database and/or compute selfprojecting realization spaces of matroids in OSCAR, you need to use the developers version of OSCAR on the branch ag/selfprojecting_matroids on <https://github.com/AlheydisGeiger/Oscar.jl/tree/ag/selfprojecting_matroids>. This will be incorporated into the experimental section of the regular version soon.
