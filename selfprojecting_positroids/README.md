## Code for positroid computations

This directory contains the code and output files for the computation of self-projecting positroids and orthopositroids. 

We study positroids on up to 10 elements of rank at most half the size of the ground set.
The file `data_iso_positroids.sobj` contains the isomorphism classes of positroids for each (k,n).
The file `data_selfprojecting_positroids.sobj` contains the isomorphism classes of self-projecting positroids.
The file `data_orthopositroids.sobj` contains the isomorphism classes of orthopositroids with respect to some $\lambda$.
